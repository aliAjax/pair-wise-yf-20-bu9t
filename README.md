# hxyfront-62008 烟花燃放脚本编排

面向编排师、点位负责人、安全员三方协同的燃放脚本编排台。节目段落 → 点火节点 →
燃放点位三层数据在同一份脚本里维护，并带安全重算、放行锁定、并发冲突和原子发布。

## 核心规则

- **节点绑定**：每个点火节点绑定烟花型号（含要求安全距离）、发射仰角/方位角、点位、点火时间。
- **安全重算**：点位移动或风向风速变化时，受影响节点（同点位/全场）的可用状态立即置为
  “待重算”并异步逐节点核算；重算未完成时，**整场预览与发布一律停住**。
- **放行锁定**：只有安全员能放行段落，且要求段内节点全部核算通过。锁定后编排师不能改节点、
  点位负责人不能拖相关点位，必须先由安全员“撤销放行”。
- **并发冲突**：节点带 `nodeVersion` 乐观锁。两个窗口同时改同一节点时，晚到的修改被拒绝，
  节点保留在原段落，并在编辑器红条 + 冲突中心留痕；真实双开标签页通过 `storage` 事件同步。
- **原子发布**：发布走「阶段包写入+回读校验 → 正式包提交+校验 → 清理阶段包」。
  任一步失败都会回滚到**上次完整版本**，半份脚本永远不会被当作已发布；重启时发现残留
  阶段包也会丢弃。正式包带 FNV 校验和，篡改/半写可被识别。

## 角色

- **编排师**：维护节目段落与点火节点。
- **点位负责人**：平面图拖拽点位、更新风向风速（触发重算）。
- **安全员**：核算完成后放行/撤销段落，执行发布。

## 技术栈

React 19 + Vite + TypeScript，本地存储 localStorage（不可用时自动降级内存）。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62008
npm run build    # 类型检查通过后产物输出到 dist
```

## 演示路径

1. 首屏自动重算：近景 E 点礼花束因安全距离不足判定“不可用”，发布被闸门拦住。
2. 切到**安全员**放行 Intro；再切回**编排师**，该段落节点只读。
3. 右下角“并发冲突 · 发布审计”可模拟两个窗口同时保存同一节点，观察晚到修改被拒、
   原段落保留。
4. 把近景节点改绑到后场 D 点，等待重算变绿；安全员放行全部段落后发布。
5. 点“🧪 模拟下次写入失败”再发布，观察回滚提示与审计记录，正式版本保持不变。
